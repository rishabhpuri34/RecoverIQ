Machine Learning Model

How RecoverIQ Predicts

RecoverIQ uses a Ridge Regression model trained on historical struvite reactor operating data to estimate phosphorus conversion.

Prediction Inputs

The following user-entered operating variables are used to generate predictions:

  • MgCl₂ dosing (L/min)
  • NaOH dosing (L/min)
  • Feed orthophosphate (mg/L)
  • Temperature (°C)

What About Recycle Flow?

Recycle flow is recorded and saved with each scenario, but it does not currently influence the machine learning prediction.

Understanding the Baseline

Predictions are compared against a fixed historical model baseline rather than real-time reactor measurements.

Important: Research Prototype

Predictions represent statistical associations, not guaranteed outcomes from changing operating conditions. Historical ranges are not recommended operating conditions, and being within each range does not guarantee that an input combination is reliable.

RecoverIQ is a research prototype. Model predictions are generated from historical operating data and saved with each scenario. No commands are sent to physical reactor equipment. Predictions should not be used as operational recommendations without further validation.
